Discord Relay & Feeds

Server Client Needs webhook URLs Hot-reload

What it does — and why you would use it

This module mirrors selected in-game events straight into your Discord channels as tidy rich-embed messages, and drives each player’s own Discord Rich Presence card (“Playing …” with your logo, the live online count and a session timer). It uses Discord incoming webhooks — a one-way HTTPS post — so there is no bot to host, no login, and players cannot influence it.

Five independent event feeds, each pointed at its own channel, plus Rich Presence:

  • Kill Feed — every genuine enemy-race PvP kill (the same event as the in-game PvP Kill Feed banner), killer vs victim with their race colours.
  • Chat — public chat lines (global / race / notice / map), channel-filtered. Whispers, party, guild and trade are never relayed.
  • Megaphone — the in-game megaphone ads players shout, sender and full text.
  • Boss — a scheduled pit boss spawning or being defeated (name, map, and the killer) — the map shows its friendly name if you set one.
  • Upgrade — equipment enhancement: a successful roll (player, item by its real name, new +N) or an item destroyed on a failed roll, filtered by a minimum level so you only see the notable hits.

It is a server-only setting: the Zone server owns every value and makes every outbound call, and there is no client config file. (Rich Presence values are pushed from the server to each client, so you still set them only here.) A small LogoURL and ServerName you set once ride on every post.

Getting a webhook URL

Each feed posts to a webhook URL you copy from Discord. Make one per channel you want to use:

  1. In Discord, open Server Settings → Integrations → Webhooks.
  2. Click New Webhook, pick the channel (e.g. #killfeed), then Copy Webhook URL.
  3. Paste that URL between the quotes for the matching feed in Discord.lua.
A webhook URL is a secretAnyone who has a webhook URL can post to that channel. Keep them in this config file only — do not paste them in public, screenshots or guides. A blank Webhook = "" simply means that feed is off, so leave any channel you do not use empty.

How to activate it

  1. Open the file. .Server\Zoneserver\RF_Bin\Modules\Discord\Discord.lua in Notepad.
  2. Make sure the master switch is on. Enable = true at the top (set it to false to silence the whole relay).
  3. Paste your webhook URLs into the feeds you want (see Getting a webhook URL). A feed with a blank URL stays off even if its Enable = true.
  4. Save — no restart. A running zone re-reads the file within a second. Post volume is throttled so a busy server never trips Discord’s rate limit.
  5. Test it. Trigger one event you enabled (a PvP kill, a megaphone, a boss spawn) and check the matching channel.
Do not delete the fileDiscord.lua is required when the Zone server starts — deleting it stops the server from booting. To turn the relay off, set Enable = false (or just leave every Webhook blank) instead of removing the file.

The config file

One Lua file, plain-language comments included. The global keys sit at the top; each feed is its own { Enable, Webhook } block; Rich Presence is the RichPresence block. Every value is clamped to a safe range and a typing mistake is reported in the Module Logs.

Discord = {
  Enable            = true,    -- master switch: false sends nothing at all
  MinSendIntervalMs = 1500,    -- shortest ms between two posts (Discord allows ~30/min)
  MaxQueue          = 100,     -- most queued posts kept if Discord is unreachable
  LogoURL           = "",      -- optional image URL shown as a logo on every post
  ServerName        = "RF ONLINE NEXT", -- footer / author line on every post

  KillFeed  = { Enable = true, Webhook = "" },
  Chat      = { Enable = true, Webhook = "", Channels = { "ALL", "RACE", "NOTICE" } },
  Megaphone = { Enable = true, Webhook = "" },
  Boss      = { Enable = true, Webhook = "" },
  Upgrade   = { Enable = true, Webhook = "", MinLevel = 1 },

  RichPresence = { ... }       -- see "Rich Presence" below
}
KeyDefaultMeaning
EnabletrueMaster switch for the whole relay. false = no feed posts anything, regardless of each feed’s own flag.
MinSendIntervalMs1500Global anti-flood: the shortest time between two posts. Discord allows ~30 webhook calls/minute per channel, so keep this ≥ 1500.
MaxQueue100How many pending posts are kept if Discord is unreachable; the oldest are dropped. All sending runs on a background thread, so the game never stalls on Discord latency.
LogoURL""A publicly reachable image URL shown as a small logo beside the server name on every post. Empty = none.
ServerName"RF ONLINE NEXT"The name shown as the footer / author line on every webhook post (Rich Presence has its own separate name).

The event feeds

Each feed turns on with its own Enable and a non-empty Webhook. The Boss feed follows the same death-announcement blacklist as the in-game boss notice, and shows the map’s friendly name when BossRespawnMap.lua provides one. The Upgrade feed shows the item’s real display name (not its internal code).

Feed blockKeysWhat it posts
KillFeedEnable, WebhookEnemy-race PvP kills — killer vs victim, each with its race colour.
ChatEnable, Webhook, ChannelsPublic chat. Channels lists which in-game channels to relay (case-insensitive): "ALL" global shout, "RACE", "NOTICE", "MAP". Private / party / guild / trade are always skipped.
MegaphoneEnable, WebhookIn-game megaphone ads — the sender and the full message text.
BossEnable, WebhookPit-boss spawn / defeat — boss name, map (friendly name if set) and the killer.
UpgradeEnable, Webhook, MinLevelSuccessful upgrades (player, item name, new +N) and items destroyed on a failed roll. MinLevel filters by tier: 1 = every upgrade, 5 = only the rare +5/+6/+7 hits (and losses of +5 gear); 0 also catches base (+0) losses.

Discord Rich Presence

Rich Presence is per-player and drawn by each player’s own Discord desktop app: while they run the game their Discord shows “Playing <your app name>” with your logo, the live online count and a session timer. The values are pushed from the server to every client on world entry, so you configure them only here — nothing is baked into the client. AppID and LogoAsset are public (not secret).

RichPresence = {
  Enable       = true,
  AppID        = "",               -- Discord Application ID (discord.com/developers);
                                   -- the app's NAME shows as "Playing <name>"
  LogoAsset    = "rflogo",         -- art-asset key uploaded under Rich Presence > Art Assets
  ServerName   = "RF ONLINE PROTECTION", -- top line of the card
  InviteUrl    = "",               -- a discord.gg invite -> a clickable card button (empty = none)
  ButtonLabel  = "Join our Discord", -- button caption (Discord caps it at 32 characters)
  ShowPlayers  = true,             -- include the live online player count
  ShowUptime   = true,             -- include the running timer (since the zone started)
}
  • AppID comes from your application at discord.com/developers; the application’s name is what shows as “Playing …”.
  • LogoAsset is the key of an image you uploaded under Rich Presence → Art Assets on that application.
  • InviteUrl adds a clickable button to the card; leave it empty for no button.
The protection line is fixedThe “DtZProtect” anti-cheat text on the card is fixed in the server on purpose and cannot be edited here. Everything else on the card — name, logo, player count, uptime, button — is yours to set.
