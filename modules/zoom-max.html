Camera Zoom Max

Server Client Hot-reload

What it does — and why you would use it

The game caps how far each race’s camera can pull back (zoom out) when a player scrolls the mouse wheel or holds Page Down. Those stock ceilings are 250 (Bellato), 275 (Cora) and 290 (Accretia) world units. This module lets you raise them so players get a wider, more top-down view — useful for spotting events, coordinating a war, or just surveying the map.

It is a server setting: the Zone server reads ZoomMax.ini and pushes the per-race ceilings to every client on world entry and after each live edit, so a player cannot edit their own zoom limit. There is no client file.

PartWhere it livesIts job
Server limits.Server\Zoneserver\RF_Bin\Modules\ZoomMax\ZoomMax.iniMaster on/off plus a max zoom-out distance for each race.
Client halfNo client file. The server pushes the numbers and the client lifts its camera ceiling for both the mouse wheel and Page Up / Page Down. Both the Zone server and the game client must be the current build.
Only zoom-OUT is touchedThis changes the far limit. How far you can zoom in (and the zoom speed) are unchanged. Zooming is symmetric otherwise: Page Up / wheel-up still zooms in, Page Down / wheel-down still zooms out — just, now farther.

How to activate / extend it

  1. Open the file. .Server\Zoneserver\RF_Bin\Modules\ZoomMax\ZoomMax.ini in Notepad.
  2. Turn it on. Set [General] Enable = 1 to use your own ceilings (with 0 every player keeps the stock 250 / 275 / 290).
  3. Raise the numbers. Set MaxZoomOutBellator / MaxZoomOutCora / MaxZoomOutAccretia to the distance you want (whole world units, 10–5000). For example 600 for a much wider view.
  4. Save — no restart. A running server hot-reloads and re-pushes to every online client; the new far limit applies to their next zoom.
  5. Test it. Log in and scroll the wheel down (or hold Page Down) — the camera now pulls back to your new ceiling instead of stopping at the stock one.
Do not delete the fileZoomMax.ini is required when the Zone server starts — deleting it stops the server from booting. To go back to the stock camera limits, set [General] Enable = 0 instead of removing the file.

The config file

One file, one [General] section. Every value is in whole world units and is clamped to 10–5000 (a value out of range is reported in the Module Logs and the nearest allowed number is used).

KeyStock defaultMeaning
Enable1 (at stock values)1 = use the three ceilings below; 0 = restore the normal stock limits for every race.
MaxZoomOutBellator250Far zoom-out distance for Bellato (both male and female).
MaxZoomOutCora275Far zoom-out distance for Cora (both male and female).
MaxZoomOutAccretia290Far zoom-out distance for Accretia.
Ships at stockThe file is delivered with Enable = 1 but the ceilings set to the stock 250 / 275 / 290, so installing it changes nothing until you raise a number. Leave a key out or at its default to keep that race behaving exactly like stock.

A larger number lets the camera sit farther from the character (see more ground, smaller figures); push it too high and the world can look distant and the character tiny — pick what is comfortable for your server.
