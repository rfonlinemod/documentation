Additional Settings (TAB Auto-Target)

Server Client Ships off Hot-reload

What it does — and why you would use it

Additional Settings is the server’s bag of extra client switches that have no file of their own. Its first entry is TAB auto-target: with it on, a player taps TAB to instantly target — and taps again to cycle — the nearest eligible target within a range you set, instead of fumbling to click a mob in a crowded field.

You choose how far TAB reaches and what it may target (monsters, enemy players, both, or just whatever each player’s own in-game Options allow). The server resolves the settings and pushes them to every client as they enter the world — there is no client file to edit.

PartWhere it livesIts job
Server switch.Server\Zoneserver\RF_Bin\Modules\AdditionalSettings\AdditionalSettings.ini (+ AdditionalSettings.lua)Turns TAB auto-target on and sets the reach and what may be targeted.
Client halfNo client file. The server pushes the resolved settings to each client, which re-binds TAB accordingly. When the module is off, TAB keeps its stock rotate-to-next-target behaviour.
Off by defaultThe module ships Enable = 0, so TAB is unchanged until you turn it on. Because the client re-binds TAB when the feature is pushed, both the Zone server and the game client must be the current build for it to work.

How to activate it

  1. Turn it on. Open .Server\Zoneserver\RF_Bin\Modules\AdditionalSettings\AdditionalSettings.ini in Notepad: 
    [AdditionalSettings]
Enable = 1
AutoTargetRange = 500
AutoTargetType = 3
    Save it — a running server hot-reloads and re-pushes to every online client.
  2. Set the reach. AutoTargetRange is the maximum distance, in world units, TAB will grab a target from (larger reaches further across the map; clamped 1..2000).
  3. Choose what TAB cycles. Set AutoTargetType from the legend below — monsters, enemy players, both, or defer to each player’s own Options.
  4. Nothing to do on the client. Eligible clients re-bind TAB automatically on the push.
  5. Test it. Stand near a few mobs (or players) and tap TAB — the first tap targets the nearest match, and each further tap advances to the next one and wraps around.
Do not delete the fileLike every module, AdditionalSettings.ini is required when the Zone server starts — deleting it stops the server from booting. To turn the feature off, set Enable = 0. (The companion AdditionalSettings.lua is optional and may be absent.)

The config file

One file, Modules\AdditionalSettings\AdditionalSettings.ini, with an optional AdditionalSettings.lua beside it — a value set in the Lua wins over the .ini. Both hot-reload live.

KeyMeaning
EnableMaster switch for TAB auto-target. 1 = on, 0 = off (stock TAB).
AutoTargetRangeHow far (world units) TAB reaches for the nearest target. Clamped 1..2000.
AutoTargetTypeWhat TAB cycles between — see the legend below. Clamped 0..3, default 3.

Choosing what TAB targets (AutoTargetType)

ValueTargets
0Monsters only.
1Other-race players only — enemy players, not your own race.
2Monsters + other-race players.
3Default — defer to the in-game Options. TAB cycles whatever each player’s own Options → Targeting “check target” boxes allow (Monster / Bellato / Cora / Accretia); own-race players are targetable only if that player has ticked their own race.
  • The Options filters always apply. Whatever type you set, a candidate is only chosen if the player’s matching in-game race / monster target filter is on — the module never grabs something the player has filtered out.
  • Dead and allied mobs are skipped. TAB never targets a corpse or a friendly / allied creature.
  • It cycles, it does not re-pick. The first tap picks the nearest match; each further tap advances to the next-nearest and wraps back round, so you can walk a target list with repeated taps. A fresh tap fires instantly and hammering the key is rate-limited, so it cannot flood the server.

With Enable = 0 the settings are ignored entirely and TAB behaves exactly as stock RF Online.
