★What you are running

An RF Online private server is three programs working together, plus a database, plus the game client on each player's PC. They must be started in order.

ProgramFile you double-clickJob
Account ServerAccountServerSD.exeLogins, accounts, passwords
Login ServerLoginServerSD.exeServer list, billing / premium status
Zone (Game) ServerZoneServer_Regular_1_0_x64.exe (use run.bat)The game world: maps, monsters, characters

Full instructions, prerequisites and the database names live in the Server & Client guide.

⚙Documented modules

Optional modules ship switched off and are turned on by editing a small text file — no recompiling. Each one is documented only after it has been tested, so this list grows over time.

ModuleTypeWhat it does
Welcome WindowClientAnnouncement window shown when a player enters the game
Quest Monster MarksClientYellow markers above the monsters a player still needs to kill for a quest
Chat LogServerWrites every in-game chat line to a log file for moderation and audit
Box StackServerLets box-open rewards merge into an existing inventory stack instead of using a new slot
Potion EffectsServerNew potion rewards (money, points, buffs, premium, megaphone…) plus endless potions
Potion Lua OverridesServerOverride what a specific potion does from one Lua list, without editing item scripts
MegaphoneServer ClientPlayers right-click a configured potion to compose a styled announcement (font, color, effects) broadcast to every player and mirrored in chat
Boss Respawn ScheduleServer ClientPit bosses respawn on exact weekly / one-off date-times from one simple Lua file, with an in-game countdown window on the BOSS button
Election ManagerServerGoverns the patriarch / archont (race leader) election: candidate register price, extra vote / register eligibility gates, and whether the live vote-score list is shown

See the Modules / Features page for activation steps and full configuration. More modules are added here once they are tested.
